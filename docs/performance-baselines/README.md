# Recorded benchmark reports

These JSON reports and CPU profiles preserve measurements from synthetic fixtures and local browser runs. The filenames retain their original development-stage identifiers so reports can be matched to earlier commits and reproduced by the existing scripts.

Use the feature guides to interpret the results:

- [Benchmark procedure and measurement limits](../performance-benchmarks.md)
- [Viewer quality](../viewer-quality.md) and [hotspot visibility](../hotspot-performance.md)
- [Runtime assets](../runtime-assets.md), [spatial rendering](../spatial-rendering.md) and [room streaming](../room-streaming.md)
- [HQ lighting](../hq-rendering.md)
- [Chunking baselines](../chunking-baselines.md) and [acceptance results](../chunking-acceptance.md)

Software-renderer results establish fixture correctness and relative work counts. They do not establish physical-device frame rates, thermal behavior or production memory budgets. Reports are historical evidence; current verification commands are documented in the feature guides.
